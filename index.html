Passo a passo

Rode os comandos na pasta do projeto.

  1. 01

    Conecte sua conta

    gh auth status
    Mostra qual conta está conectada no terminal.
    gh auth login
    Conecta sua conta, caso o terminal peça login.
  2. 02

    Faça o commit

    git status
    Mostra o estado dos arquivos. Se a pasta ainda estiver sem Git, rode git init -b main para começar na branch main.
    git add .
    Prepara as mudanças para o commit. Confira a lista com git status --short. Use o .gitignore para excluir arquivos locais, como .env.
    git commit -m "Commit inicial"
    Registra as mudanças preparadas em um commit local.
  3. 03

    Envie ao GitHub

    git remote -v
    Lista os apelidos e as URLs dos remotos já configurados.
    gh repo create …
    Cria o repositório e envia os commits com --push. Troque pixel-rain pelo nome do seu projeto.

O que muda no comando

Quem consegue ver o repo?

--public
Qualquer pessoa pode ver o repositório.
--private
Só quem tem permissão pode acessar.

Qual nome usar para o remoto?

Um remoto é um endereço Git salvo com um apelido local.

--remote=origin
origin é o nome mais comum para o remoto principal.
--remote=github
Use github se quiser manter o origin existente e esse novo apelido estiver livre.
--source=.
Usa o repositório Git da pasta atual.
--push
Envia os commits da branch atual ao GitHub.
